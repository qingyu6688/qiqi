# 柒柒接口设计文档

## 桌面 HTTP 连接错误

`http_send` 的错误包含 message（中文原因）与 retryable（是否确认可在连接建立前重试）；前端兼容旧的纯字符串错误。证书校验、请求头或地址错误、HTTP 限流、重定向后失败和响应体断流不触发自动重发。临时连接失败仅最多补两次，等待过程受原超时和取消信号约束。

## 1.1.0 多图请求

同步 Images API 多图拆为单图请求，普通兼容接口显式发送 n=1；Codex CLI 仍按兼容规则省略其不支持的参数。质量参数不因普通多图拆分而降级。图生图的每次请求均携带原参考图和遮罩。

异步接口从画廊拆成独立任务，每次只要求一张。Responses 多图沿用独立图片工具调用。对话手动数量在工具 schema 中限定数组条目数，服务端未遵守条目数时会报错并停止图片提交，不会把一条五主题提示词直接当作五个文件。

尺寸适配发生在接口返回后、图片入库前，不伪称接口原生支持了指定尺寸。适配后显示和普通下载使用目标像素尺寸，原文件通过独立字段保存并可下载。

## 文本与图像配置入口

“文本 API”页面独立维护 `provider=openai`、`apiMode=responses` 的配置，使用该配置自己的地址和 Key 请求 `GET /v1/models`。选择结果沿用现有 profile 的 `model`、`selectedModel` 字段，不新增密钥字段或持久化格式。

点击“用于对话生图”写入 `agentApiConfigMode=hybrid`、`agentTextProfileId` 和 `agentImageProfileId`，不修改画廊的 `activeProfileId`。文本模型通过 `POST /v1/responses` 理解历史文字和图片并调用工具；图像模型继续通过原有图片接口生成或编辑。文本模型只返回文字时可正常展示回复。

图生图按钮沿用参考图上传和任务提交链路。OpenAI Images 配置有参考图时使用 `POST /v1/images/edits`，以 multipart 携带 `image[]` 和质量等参数；无参考图时继续请求 `images/generations`。

维护：maorongkang@gmail.com。

本期没有新增公共后端接口，沿用已有供应商适配层。

| 用途 | 接口 | 条件 |
| --- | --- | --- |
| 读取 Key 可用模型 | `GET /v1/models` | 当前地址和 Bearer Key，不提交生图 |
| 文本生图 | `POST /v1/images/generations` | OpenAI 兼容图片供应商 |
| 参考图编辑 | `POST /v1/images/edits` | 供应商须支持编辑及对应图片格式 |
| 对话与工具调用 | `POST /v1/responses` | 文本模型须支持看图、Responses 和工具调用 |
| 自定义异步图片 | JSON 中定义的提交、查询路径 | 按服务商实际文档配置 |

## 对话模式

- 原生模式：对话 API 本身支持 `image_generation` 工具。
- 混合模式：对话 API 调用自定义工具，随后应用调用独立图片 API；图像供应商可使用 Image2Pro 等已测通的配置。
- 图片接口的调用成功不能替代对话 API 的工具调用验证。

## 参数

`quality=high` 在关闭 Codex CLI 兼容模式时可由 Images API 发送，是否实际使用该档位由供应商决定。不要把提示词中的“高质量”当作请求参数。测试 Key 不预置，所有请求通过现有 lib 接口模块发送。

## 1.1.1 请求控制

- Images、Responses 单图、自定义供应商、fal 及原生对话使用同一个两名额队列，拿到名额后才启动请求计时。文本规划和标题请求不占生图名额。
- Responses 原生单次工具调用限制为 1，禁用并行工具调用。自动模式本轮图片请求总数上限 10，失败也扣除预算；批量参数在请求前校验，不默默截成另一数量。
- 已成功提交本地图片后断流，批量工具仍返回成功。未收到完成图片的中断不会自动重新生成。
- 重试沿任务的 profile 和 model，并保留对话关联；找不到配置/模型时拒绝重试，用户可通过复用后重新提交选择另一配置。
- 历史文字预算 48,000 字符，近期 6 轮优先保留完整文字，早期用标注为可能不完整的摘录。非明确引用历史图最多 4 张且编码总量 8 MiB；当前附件和明确引用的旧图优先，编码总量超过 32 MiB 明确报错。当前文字上限 96,000 字符，连续工具调用文字上限 192,000 字符。本地原文和图片不删除。

自定义异步接口入队后保留取消信号，轮询时限为配置超时与 600 秒中的较大值；超时只保留原任务编号待恢复查询，不重新提交生图。fal 每次请求使用独立客户端，避免并发配置混用；SDK 的生成 POST 错误不会触发自动重复提交。
