# 柒柒本机记忆版交付记录

日期：2026-10-26。维护：maorongkang@gmail.com。

本期确认产品名称为柒柒，采用用户提供的 Logo，同时提供网页与 Windows 桌面版。沿用既有多轮生图能力和本地存储，各端独立保存，不加入账号系统或云同步。

重点改动为品牌、安装信息、独立更新来源及按 Key 读取模型。没有删除原有画廊、图片编辑、遮罩、批量、对话分支或数据备份能力。保存格式和旧导入协议保持兼容，原作者与第三方许可继续保留。

模型列表通过现有网络封装访问，避免网页和桌面使用不同请求实现。界面把网络权限错误与无模型权限分开提示，修改 Key 时旧请求会取消。模型目录只保留在组件内存，已选模型仍使用原配置格式保存。

后续可按实际使用情况增加长对话摘要、角色资料和统一请求限流；这些功能没有在本期承诺为已实现。若未来需要跨端同步，再设计账号、服务端存储及冲突策略。

本期没有创建远程仓库、推送代码或发布外部网站，也没有把测试 Key 写入安装包或源码。具体构建、测试和未覆盖项见“测试报告.md”。

## 2026-10-30 桌面修复

本轮针对桌面生图失败后的状态判断、应用级排队、持久化故障、重试串配置和长期对话请求膨胀进行修复，同时补齐 Windows 本地 Key 加密。保留原配置、对话和图片；没有调用付费生图，也未部署网页版。供应商本身的超时、限流与证书错误仍需服务端处理，客户端不会通过关闭证书验证或盲目重复提交规避。
