# 柒柒用户使用手册

维护：maorongkang@gmail.com。

## 生图与编辑

画廊数量表示独立图片文件数。数量设为 4 就生成 4 张；需要 5 张时设为 5。描述多个主题时按顺序列出，每张会收到独立请求。若要一张拼贴作品，请明确要求“一张拼贴图”，数量设为 1。

指定尺寸或比例后，接口结果会完整保留内容，等比缩放并补边到所选尺寸。不会裁掉海报文字，也不会拉伸主体；“自动尺寸”保留服务商原始尺寸。详情中的“下载原图”保留尺寸适配前的文件，普通下载和后续参考图使用已适配的图片。透明图片的补边保持透明，其他图片使用白色补边。补边是本地尺寸处理，不是模型扩图。

在设置中填入自己的供应商地址和 Key，再读取并选择模型。画廊适合单次生成和批量任务。点击输入栏的“图生图”直接上传参考图，输入修改要求后提交；支持多张参考图。旁边的下拉菜单可添加图片链接、打开画板，也可在参考图预览中添加遮罩。单次多图最多同时请求两张，其余依次排队；批量提示词的并发设置仍约束提示词任务数。

回复底部显示当前阶段、已用时间及图片完成、生成中、排队和失败数量。进度条反映已处理的图片任务数量，失败不会清除成功图片。点击停止后不再发出排队任务；重新生成整轮可能重新计费，单张失败可使用对应任务的重试按钮。

桌面版遇到确认尚未发出 HTTP 请求的临时连接故障时，会等待后自动补试，最多两次。证书校验失败、服务限流及响应中断仍需检查 API 地址、网络或服务状态；程序不会关闭证书校验或盲目重发已提交的图片请求。

sub2api 与 OpenAI 兼容配置不需要手填模型：填入 API 地址和 Key，点击“读取模型”，再勾选列表中的模型。可搜索和多选，选中后自动保存并可在首页切换。换 Key 后需要重新读取；如果列表为空，先检查该 Key 的分组和模型权限。读取失败时按界面提示检查地址、网络或网页跨域设置。

## 记住上下文

输入栏“数量”可选“自动”或 1–10 张。自动跟随提示词；固定数量会逐张生成，达到本轮数量后不自动追加或补图。仅聊天时不会因为设置了数量而触发生图。生成失败的图片需要手动重试，避免连续产生额外请求。

切换到“对话生图”。例如第一轮“画一只红色陶瓷杯”，第二轮“改成蓝色，保持构图”。同一对话会带入历史文字和图片，也可以使用 @ 指定参考图。关闭后，重新选择原对话继续；新建对话会开启独立上下文。

对话需要能看图并支持工具调用的文本模型。在“设置 → 文本 API”点击“添加文本 API”，填写文本接口的地址和 Key，读取并勾选文本模型，然后点击“用于对话生图”，即可关联已有图像配置并启用混合模式。两个 API 可以使用不同服务商和 Key；添加、编辑文本配置不会切换画廊的当前 API。此后可到“对话生图配置”调整原生或混合模式及关联接口。当前对话引擎使用 Responses API；供应商只支持 Chat Completions 时不能直接用于此对话流程。

记忆不会自动跨新对话共享，也不能保证无限长历史或人物外观完全一致。多轮角色创作请保留角色参考图，在描述中明确需要保持的特征。

## 保存与迁移

网页版保存在当前站点和浏览器，桌面版保存在本机 data 目录，两者不自动同步。在设置的数据管理中导出 ZIP，再在另一端导入。带 API 配置的备份可能包含 Key，分享前先检查。

## 质量档位

选择 high 可将对应请求参数发给支持的接口。要实际发送 quality，关闭 Codex CLI 兼容模式。服务商没有返回实际档位时，界面的选择不能证明上游采用了该档位。

## 1.1.1 桌面使用说明

多图任务共用两个生图名额，其余排队等待；排队不占接口超时时间。自动数量每条消息最多请求 10 张，更多图片请分次发消息。重试图片会沿用原配置和模型，对话里的结果仍在原轮次。

长对话会保留最近内容，并减少未明确引用的历史图片。当回复处显示上下文说明时，旧记录仍在本机；要继续处理较早的图，请明确引用该图。

若出现“本地数据尚未保存”，请保持客户端打开，检查磁盘空间与数据目录权限后点击“重试保存”。写完前关闭或安装会被拦下。

API Key 在当前 Windows 账号下加密保存。换电脑、换 Windows 用户前，请在原机应用内导出配置或备份，再在新机导入；导出文件包含密钥，请自行保管。直接复制 data 目录到不同账号无法解密。
