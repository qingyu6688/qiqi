# 柒柒需求规格说明书

版本：1.1.0。日期：2026-10-29。维护：maorongkang@gmail.com。

## 图片数量与精确比例

- 回复区域需显示当前生成阶段、实时用时、成功、排队与失败张数；单张失败或后续文字中断不得隐藏已生成图片。
- 单次多图限制并发，取消后停止排队提交。桌面端只对确认未发送 HTTP 请求的临时连接故障重试，不自动补生成失败的图片。

- 画廊数量控制独立图片文件数，多主题按顺序逐张请求，避免一张拼贴替代多张作品。
- 对话生图可选择自动或 1–10 张，设置保存到本机；固定数量限制本轮图片请求，失败图片不自动补图。
- 指定尺寸的输出必须等比适配到目标尺寸，完整保留内容，必要时补边，禁止拉伸或裁剪。
- 原始图片可单独下载，并随任务备份、恢复和删除管理。自动尺寸保持服务商原始尺寸。

## 图生图与文本 API 入口

- 网页版和桌面版输入栏提供可直接上传参考图的“图生图”按钮，支持多张参考图及已有遮罩、画板流程。
- 设置侧栏提供“文本 API”，支持独立地址和 Key、读取模型后选择、一键关联已有图像 API。
- 文本配置用于 Responses 多轮对话和工具调用，编辑文本配置不得替换画廊当前生图接口。

## 已确认范围

- 产品名称为“柒柒”，提供网页版和 Windows 桌面版。
- 使用用户提供的 PNG Logo 原图，生成桌面图标；不改画 Logo 内容。
- sub2api 与 OpenAI 兼容配置按当前地址和 Key 读取模型列表，再勾选使用，无需手填模型 ID。
- 先实现本机记忆，各端独立保存，不引入登录与云同步。
- 保留图片生成、参考图编辑、遮罩、批量提交、画廊和备份功能。
- 沿用已有多轮对话生图：后续请求带入当前分支的历史文字、参考图和已生成图片。
- 对话关闭应用后仍保留，重新打开同一对话可以继续；新对话相互独立。
- 保留原项目及第三方许可声明，产品名称、图标和安装信息使用柒柒。

## 本期限制

- 上下文来自本机历史重建，并非模型自动永久记忆；历史仍受供应商上下文容量限制。
- 本期未新增跨对话的角色档案、长期偏好提取或自动摘要。
- 图像接口成功不代表对话能力已测通。对话模型还需要支持看图、Responses 和工具调用。
- 不把测试 Key 写入源码、预置配置、文档或安装包。

## 验收

1. 网页标题、导航、安装名称和应用图标显示柒柒。
2. 画廊与对话生图均可进入，原有编辑、批量和数据管理入口保留。
3. 对话按活动分支拼装历史文本和图片，旧格式导入仍可读取。
4. 未配置自有更新源时，不查询或安装原项目的更新。
5. 测试、前端构建及 Windows 打包完成；真实接口验证与构建验证分开记录。
