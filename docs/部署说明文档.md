# 柒柒部署说明文档

维护：maorongkang@gmail.com。以下命令在项目根目录执行。

## 发布范围

当前仅维护和发布 Windows x64 桌面端，发布仓库为 [qingyu6688/qiqi](https://github.com/qingyu6688/qiqi)。GitHub Pages、Vercel 与 Docker 不属于本期发布范围。前端源码仍用于 Tauri 内嵌界面，不需要部署网站。

## 开发环境

需要 Node.js 24、npm、Rust stable、Visual Studio C++ 构建工具与 Windows SDK。环境版本记录见[环境检查](环境检查.md)。

```powershell
npm ci
npm run tauri:dev
```

开发界面默认由本机 5173 端口提供。客户端读取 `src-tauri/.env` 和 `.env.local`，不读取根目录的 env 文件。API Key 通过应用设置输入，仓库不提供预置 Key。

## 桌面安装包

```powershell
npm run tauri:build -- --bundles nsis
```

Tauri 默认构建配置将内嵌界面输出到 `dist-desktop/`，不覆盖现有 `dist/`。安装包位于 `src-tauri/target/release/bundle/nsis/`。正式发布需要签名私钥和密码环境变量，具体见[桌面发布签名说明](桌面发布签名说明.md)。安装到当前用户可写的独立目录，避免与原项目共用安装目录。

## 本机数据与覆盖更新

应用标识固定为 `local.qiqi.studio`。默认数据目录为安装目录下的 `data`，包括 SQLite 数据库、图片、缩略图和客户端状态。用户修改过目录时，以 `data-dir` 指向的位置为准。

覆盖更新前，应先正常关闭程序，完整备份现有安装目录及实际数据目录。保留数据库旁的 WAL 文件和图片子目录；不要仅复制数据库文件。运行新版安装器时沿用原安装位置，不选择删除应用数据。

1.1.1 将 Windows API Key 迁移为当前系统用户的 DPAPI 加密格式，SQLite schema 为 3。旧版不能直接读取新版数据库。回退时恢复升级前整份备份，不能只替换旧 exe。跨电脑迁移优先使用应用内导出、导入，导出的配置可能含明文 Key，应妥善保管。

1.1.2 的自动更新在安装前等待设置、任务和对话保存完成，保存失败会阻止安装；安装器使用 `/UPDATE` 更新原安装目录，保留现有数据。更新包下载后和安装前均校验签名，缓存重启后也会重新校验。

1.1.1 及更早版本未内置柒柒更新源，需要从发布页下载新版安装包，先覆盖升级一次。1.1.2 起可通过“设置 → 关于 → 检查更新”使用自己的发布源。

## 发布前检查

按顺序完成版本同步、测试、构建和签名校验，再发布正式 Release。发布包只包含程序与资源；本机 `data`、备份、密钥、开发日志不应进入 Git 或 Release。

发布版本、构建结果、覆盖安装和数据核对记录见[测试报告](测试报告.md)。具体签名配置和更新清单要求见[桌面发布签名说明](桌面发布签名说明.md)。
