# 柒柒概要设计说明书

日期：2026-10-26。维护：maorongkang@gmail.com。

## 技术选型

沿用 React 19、TypeScript 严格模式、Vite、Tailwind CSS 和 Zustand。Windows 端沿用 Tauri 2、Rust 与 SQLite。当前产品没有服务端，不需要新增 MySQL 服务。

## 目录

- `src/components/`：画廊、对话和设置界面。
- `src/hooks/`：界面逻辑及更新状态。
- `src/lib/brand.ts`：品牌名称、说明和原项目来源。
- `src/lib/agentInputBuilder.ts`：当前分支上下文与历史图片的请求拼装。
- `src/lib/api.ts`、`src/lib/agentApi.ts`：图片及对话请求。
- `src/lib/db.ts`：按平台选择 IndexedDB 或桌面存储。
- `src-tauri/`：Windows 宿主、本地文件和安装配置。
- `public/qiqi.png`：用户提供的品牌 Logo 原图。
- `src/api/models.ts`：按当前 Key 读取模型的请求层。
- `src/components/settings/ApiModelPicker.tsx`：模型列表、搜索和勾选界面。
- `docs/`：中文项目文档，原使用说明保存在“上游使用参考.md”。

## 两端关系

两端复用同一前端和生图逻辑，分别保存本机数据。网页依赖当前浏览器与站点存储；桌面版保存到安装目录的 data 文件夹。迁移使用 ZIP 导出、导入，不提供自动同步。

## 更新

网页版仅在 `VITE_RELEASE_REPO` 合法配置后查询自有 GitHub 发布仓库。桌面更新端点和签名公钥默认留空，初版不生成更新签名产物；配置自有发布渠道后才启用。Windows 安装包仍可直接构建和分发。
