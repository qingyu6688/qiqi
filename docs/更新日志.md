# 柒柒更新日志

## 1.5.0（2026-11-12）

### 新增
- 对话顶部提供「对话设定」，设置中的「对话生图配置」提供「全局自定义指令」，编辑后点击保存。角色、画风和禁止项每轮都会带入，不参与历史摘录，当前消息可覆盖固定偏好。
- 画廊「更多 → 多图方案」可以选择「保持同一方案」或「每张换一种方案」，默认保持同一方案，单张重试沿用提交时的选择。

### 修复
- 混合模式的逐张生图提示词保留本轮用户原话，核对文字、颜色、数量和禁止项，并限定每张作品的范围，任务详情保留实际提交的完整要求。
- 模型遗漏参考标签时，逐张图片请求默认附上本轮参考图，显式选择了引用的图片仍按选择处理。
- 历史生成图即使没有附图片内容，也保留编号和已有提示词，可继续按编号引用本机原图。
- 较早轮次的长消息同时摘录开头和结尾，保留末尾的要求与确认内容，本机完整记录不受影响。


## 1.4.1（2026-11-12）

- 普通对话多图按可用 Key 和全局并发名额安排每批。五个可用 Key 可以并发生成五张互不依赖的图片。
- 修正并发设置说明，并稳定默认并行运行时的桌面存储测试。

## 1.4.0（2026-11-12）

- 桌面端新增「批量配置图像 API」，默认提供五个 Key 输入框，也可一次粘贴多行。读取模型后可选择所有 Key 共用的模型。
- 点击「保存」后，图像配置和多图队列一次写入本机。已存在的相同配置可复用。

## 1.3.0（2026-11-12）

- 对话生图混合模式新增多图队列 API，可按顺序使用多个已保存配置的 Key。
- 明确逐张处理且参考图数量与成图数量相同时，客户端直接逐图排队，按并发上限发送独立请求。
- 其他固定数量的任务分批规划，提交足量图片后在本机收尾。规划失败可继续剩余图片，已完成的图片和单张失败状态会保留。

## 1.2.2（2026-11-05）

### 修复
- 网关 502、503、504、524 错误显示中文原因及重试建议，历史错误页面也能正常显示，不改写原对话记录。
- 对话尚未提交图片任务就失败时显示“重试本轮”，无需悬停寻找图标；已有图片任务保留逐张重试入口。
- 不自动重发已提交的网关失败请求，提示用户先确认服务商任务状态，避免重复生图和扣费。

## 1.2.1（2026-11-03）

### 变更
- 对话生图的数量选择使用与质量菜单一致的圆角浮层，统一阴影、选中高亮、悬停效果和深色模式。
- 数量菜单保留自动（最多 10 张）及 1–10 张独立图片选项，显示当前张数，并根据可用空间向上或向下展开。
- 参数下拉支持键盘方向键、Home、End、回车和空格选择，Escape 取消及 Tab 离开，提供可见焦点提示。

## 1.2.0（2026-11-03）

### 变更
- 同时生图请求数改由设置控制，默认 10，可关闭限制；画廊、对话、重试和单条多图共用这个上限，替代原先固定的两个名额。
- “习惯配置”新增“限制同时生图请求数”，画廊“批量”弹层中的同一设置不再依赖批量开关和执行方式显示，并更正“不限制时同时发出全部请求”的说明。

### 修复
- 单条多图任务的计时从第一个请求发出开始，不再在后续图片开始时归零；完成耗时与运行中计时一致，不含排队时间。
- 任务记录保存失败时直接标记失败、不发送生图请求，不再一直显示“运行中”；单条提交保留输入内容，覆盖重试保留原图。
- 对话回复、配置说明、更新说明和公告中的外部图片默认显示为“加载外部图片”按钮，点击后才请求，避免图片地址把内容带给第三方网站；同源图片照常显示。
- 修正 Markdown 渲染测试在默认并行运行时偶发等待超时。

## 1.1.2（2026-10-30）

### 新增
- 桌面端从柒柒自己的 GitHub 仓库检查版本、下载并安装更新。
- 更新包使用发布私钥签名，安装前核对签名与版本，拒绝损坏或被替换的安装包。

### 修复
- 重启后安装已下载的更新时重新验签，旧的无签名缓存会提示重新下载。
- 自动更新沿用当前安装目录，保留 API 配置、对话和历史图片；保存未完成时不会启动安装。

### 变更
- 发布流程仅构建 Windows 桌面安装包，通过测试与签名校验后才公开发布。
- 1.1.1 及更早版本首次需覆盖安装本版本，此后可以使用应用内更新。

## 1.1.1（2026-10-30）

### 修复
- 图片已完成并保存后，后续连接中断不会把图片工具结果误报为失败。
- 画廊、对话与重试共用两个生图请求名额，排队时不计算接口超时，取消或删除排队任务后不再发送。
- 设置、任务或对话保存失败时显示常驻提示，可重试保存；保存未完成时阻止关闭窗口和安装更新。
- 图片重试沿用原 API 配置和模型，对话图片结果附回原轮次；配置或模型不存在时明确提示。
- 自动数量每轮最多请求 10 张图片，已失败的请求也占用数量，避免模型意外追加大量请求。
- 长对话按预算发送近期文字、必要图片和较早消息摘录，并显示上下文范围；本机历史完整保留。

### 变更
- Windows 本地数据库中的 API Key 使用当前 Windows 账号加密，原配置自动迁移；跨电脑迁移请使用应用内导出与导入配置。
- 本次仅交付桌面安装包，保留原 API 配置、对话和图片数据。

## 1.1.0（2026-10-29）

- 回复显示生成阶段、实时计时与图片完成、排队、失败数量；主动停止单独计数，结束后保留耗时。
- 对话批量、画廊单次同步多图及异步多图每批最多并发两张，失败不阻断其余任务，取消后不启动排队项。
- 桌面端仅对尚未建立 HTTP 连接的临时故障退避重试两次，保留证书校验。限流、响应中断及已发送请求不盲目重发。
- 后续文字回复失败时仍展示已生成图片，保留下载与单张任务操作。

- 画廊多图逐张请求；每张请求带序号和独立画面要求，数量以控件选择为准。
- fal 和自定义异步服务商的多图拆成独立任务，保留各自队列 ID、原始主题顺序与重试序号。
- 明确尺寸的结果统一等比适配并补边，不裁剪、不拉伸；未处理原图保留在详情“下载原图”中。
- 对话生图支持自动或手动选择 1–10 张，固定数量使用对应条目数量的批量工具，并限制追加请求。
- 比例预设与自定义比例精确匹配，支持原图备份、恢复和删除清理。

## 1.0.2（2026-10-26）

- 图生图上传改为输入栏中带文字的直接入口，继续支持多张参考图、图片链接、画板和遮罩编辑。
- 设置新增独立的文本 API 页面，复用 Responses 对话接口和按 Key 读取模型的选择器。
- 文本与图像配置分别保存地址和 Key，文本配置可一键关联混合对话模式，不切换画廊当前配置。
- 对话输入按钮显示“发送消息”，移动端的 Agent 入口统一显示“对话生图”。

## 1.0.1（2026-10-26）

- 在导航、画廊和对话空状态、模型读取按钮与关于页加入猫猫头和小猫爪。
- 猫咪装饰采用 Logo 暖棕色，适配深色模式和窄屏，不拦截鼠标与键盘操作。
- 不调整生图接口、本地数据格式或模型选择行为。

## 1.0.0（2026-10-26）

- 基于 GPT Image Playground 0.8.1 建立柒柒本机记忆版，保留原项目和第三方许可。
- 网页、PWA、Windows 应用信息和图标统一使用柒柒。
- 使用用户提供的 Logo，原图内容保持一致。
- sub2api 和 OpenAI 兼容配置支持按 Key 读取模型、搜索和勾选，取消模型 ID 手填要求。
- 切换连接信息会清除旧模型列表，取消旧请求，并提示失效模型、鉴权和网络错误。
- 对话入口改为“对话生图”，说明历史文字、图片引用和本机保存方式。
- 保留独立对话、分支、参考图、图片编辑、画廊和批量任务。
- 取消默认查询原项目更新，更新缓存按柒柒发布仓库隔离。
- 客户端不再内嵌原赞助商预置，分享链接使用 qiqi 协议并兼容解析旧导入链接。
- 将原赞助弹窗调整为备份提醒，保留本机数据管理和迁移入口。
