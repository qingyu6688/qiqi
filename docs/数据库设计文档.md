# 柒柒数据库设计文档

## 1.1.0 兼容字段

对话轮次增加可选 startedAt 用于记录本次实际开始时间；缺少时回退 createdAt。运行期间可含 requestState（连接、等待、重试次数），重新载入时丢弃临时连接状态。批量图片任务可含 agentQueued，区分尚未发出的请求。均保存在原 JSON 字段内，不变更 SQLite 表或迁移版本。

任务 JSON 可包含 `independentImage: { index, total }`，保存异步单图在原多图请求中的序号；`sizeOriginalImages: string[]` 保存尺寸适配前的图片 ID，与 outputImages 按位置对应，未处理位置为空。设置 JSON 增加 `agentImageCount`，默认 auto 或 1–10 的整数。

沿用 IndexedDB 与 SQLite 的原有 JSON 记录，不修改表结构。旧记录缺少新字段时按原逻辑读取，旧对话和用户 API 配置不迁移或覆盖。

维护：maorongkang@gmail.com。

本期沿用既有 schema，没有新增迁移或修改已发布迁移。

| 数据 | 网页版 | 桌面版 |
| --- | --- | --- |
| 设置与 API 配置 | localStorage | SQLite kv |
| 生图任务 | IndexedDB tasks | SQLite tasks |
| 对话及轮次 | IndexedDB agentConversations | SQLite agent_conversations |
| 原图 | IndexedDB images | 本地文件与 SQLite images 元数据 |
| 缩略图 | IndexedDB thumbnails | 本地文件与 SQLite thumbnails 元数据 |

对话通过 ID 引用任务，任务通过图片 ID 引用图片。桌面 SQLite 保留既有索引和迁移顺序。图片按内容去重，界面使用缩略图以减少读取量。

没有云数据库、用户账号或跨端关联。网页清理站点存储可能删除历史，桌面数据随 data 目录保存；均应定期导出备份。API Key 按原设置保存机制保存在本机，备份配置可能包含 Key，不应公开分享。

## 1.1.1 桌面存储修复

- SQLite schema 追加至 3，旧 schema 的任务、对话、图片记录不变。`kv` JSON 中非空 `apiKey` 保存为 Windows DPAPI 密文对象，读取时在 Rust 内解密；旧明文首次读取时事务迁移，原用户下目录迁移不影响读取。
- 解密失败时不返回默认配置，不覆盖旧值。请在原 Windows 用户和电脑打开，或使用原机应用内导出的配置迁移；导出文件为可迁移格式，仍包含明文密钥，不能公开分享。
- 回退 1.1.0 需恢复升级前完整备份，禁止让旧客户端直接写 schema 3 数据库。已有备份不会自动加密。
- 设置防抖、任务与对话串行写入，失败保留最新快照和常驻提示，支持手动重试。退出及安装前等待三个来源全部写完，3 秒仍未完成则保持窗口打开。
- `AgentRound.contextNotice` 可选保存本轮上下文取舍说明，兼容旧记录。无跨端同步，不新增 MySQL。
